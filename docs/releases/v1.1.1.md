# L4D2Visual v1.1.1

第一人称身体（FPB）稳定性补丁，基于已通过实机验收的 view.1 测试版本。

- **第三人称过渡兼容**：将本机原生绘制门控与骨骼视觉处理分离。结合实体原点、相机相对位移和原始模型眼位距离，更早停止不适用的第一人称修正，改善打包时人物模型短暂消失。
- **返回第一人称**：独立提前隐藏头部，减少打包结束或第三人称切换回第一人称时的头部穿模，不提前移动身体或隐藏双臂。
- **动态定位**：保留原有动态定位算法及逐模型校准，不引入实验性均值定位2。
- **FreeCamera**：保留人物世界原位与原生骨骼旁路；原有外部相机接口和默认设置不变。
- **诊断**：增加 FPB 视角判定原因、原点及相机距离、实际绘制路径等记录。

上述打包与提前隐藏改进已实机确认；个别瞬间穿模仍可能出现。偶发整体骨骼处理失效及 fastpath 假设仍待复现，本补丁不修改 `cl_modelfastpath` 管理。其他功能保持不变，不保证所有人物 MOD、联机环境或 VAC 兼容。

**更新**：完全退出游戏，备份并替换 `bin/neko/plugins/L4D2Visual.dll`，可保留原有 `hud.json`。旧实验配置 `dynamicAnchor2` 不再使用。不要替换游戏自带 studiorender.dll。首次安装将 bin 合并至游戏目录。
