# L4D2Visual 0.7.4

Tank 正式版采用用户已验证的统一序列表识别。主动画和所有动画层使用相同80项表，保留出拳自动计时、投石区分、方向/范围/目标显示与实体跟随样式。

- 删除旧 Mod/MDL 动画映射及共享容器扫描。
- 删除动画事件 factory/RecvProxy 诊断、日志写入、测试状态页和测试开关，旧诊断配置不再生效。
- Tank 总开关默认关闭；画面、计时条、方向、范围和目标线默认打开。其他功能仍默认关闭。
- 保留用户确认的55%冰蓝竖条、位置和线宽，以及样式预览和独立精调。
- 保留原版与此前 Studio DLL 两种兼容配置，用户已反馈上传的原版 Studio DLL、原版 Tank 和当前测试 Mod Tank 可用。

修改动画全局序号的 Mod 可能误判，计时不保证命中/挥空或真实 AI 冷却。没有 SourceMod 依赖。新安装包只含 bin/ 和 README.md，未分发游戏 DLL、模型或用户日志。覆盖 hud.json 前先备份；保留旧配置将沿用原有开关。

验证：23 组原生测试（含 ASan/UBSan 与菜单字形）及 Windows x86 构建通过；原版419行记录回放保持9次起手/9次计时、Mod新段回放保持2次起手/2次计时，重复采样不重复触发。

**联机功能未经测试，不保障 VAC 安全。**
