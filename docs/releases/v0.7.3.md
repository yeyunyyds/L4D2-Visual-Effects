# L4D2 Visual Effects 0.7.3

将 Tank 自动计时、实体跟随、三套视觉预设和独立细调合并到正式版。进度条随 Tank 实体位置和透视缩放，朝向/范围/条可独立显示，精调页支持 - / = 调整。

默认样式采用用户提供配置：冰蓝刻度、竖条、位置 -32/-24、大小55%、箭头/范围线宽3倍。所有功能默认关闭，包含 Tank 各显示开关、喷漆及快捷操作、P2P/自动匹配、拉伸与实验、诊断。

安装包顶层仅 bin/ 和 README.md，含默认 hud.json；覆盖旧配置前请备份，保留旧配置则沿用其开关。完整源码通过 v0.7.3 标签独立下载。

23 组原生回归与 Windows x86 构建通过。Tank 计时仍为估算；事件字段校验和共享模型映射仍有限制，联机和所有游戏情况未充分测试。

**联机功能未经测试，不保障 VAC 安全。**
