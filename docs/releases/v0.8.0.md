# L4D2Visual 0.8.0

基于用户验收通过的整合测试版发布，将实体形变、共用识别修复、Tank 范围提醒和石头预测合入 main。

- **实体缩放与拉伸**：整体大小与 XYZ 比例，覆盖8种特感、8名求生者、道具、视模及动态类别，支持128/256骨骼和Studio兼容路径。
- **准星识别修复**：游戏射线与身体范围判断，角色本体优先，候选切换、本机手持；统一识别与分类菜单设置，合并旧配置覆盖，清理切图及过期结果。
- **Tank 范围内提醒**：当前攻击扇区内可显示红线、进度条红底、红色填充及实验性原生描边，支持多Tank独立判断。入口在「Tank 行为预测 → 显示内容」。
- **Tank 石头预测**：独立入口、轨迹与静态世界落点、颜色和外观控制；修正缓存落点与新轨迹时间基准不同造成的截线折返。无刀石、自动攻击或JSONL采集实验。
- 保留本地喷漆、T键及图片设置、原版Studio接入和用户HUD样式。

所有功能总开关默认关闭。新配置红线提醒默认开，其他提醒默认关；Tank显示偏好和石头轨迹/落点子项在其总开关关闭时不生效。P2P与自动搜寻默认关闭。旧配置显式值保持，更新前备份hud.json。

28组原生回归、Windows x86构建和整合版用户验收通过。正式版功能逻辑保持验收版本，正式DLL由GitHub CI根据v0.8.0源码标签重新构建并校验。石头仍采用固定重力320和假定半尺寸16的碰撞箱；落点圆不表示伤害范围，客户端估算不保证服务器真实命中。

请完全退出游戏后更新。安装包根目录仅bin/和README.md，许可证在bin内；配套源码单独提供，main不存放安装包或DLL。

**联机功能未经测试，不保障 VAC 安全。**
