# L4D2Visual v1.1.2

本次更新集中于第一人称身体（FPB）稳定性和运行性能，不增加视觉功能，不改变默认开关与配置格式。

## 第一人称身体
- 修正动态定位与手动校准反复切换导致的闪烁：短暂失败保留最近可信变换（最多 48ms），持续失败进入稳定手动回退，恢复后重新启用动态定位。
- 改进下落、水平移动及短时相机采样失败时的视角判断。
- 将 Studio 渲染标志传递至 FPB，保留阴影深度绘制的原始骨骼；识别部分次级相机回调，避免错误应用第一人称变换。
- 第三人称或未确认的兼容视角恢复原生 DrawModel 门控；FreeCamera 继续保持世界原位身体。原生门控恢复未确认时不进入空闲降频。
- 详细 FPB 诊断仅在 Debug 日志级别启用。

## 性能
- ABI 授权本身不再触发相机 Hook 安装；仅实际相机会话或手动请求激活。
- AFK 输入检查仅检测配置的移动键及鼠标增量；空闲相机路径快速返回。
- FPB 定向采集本地玩家，减少无关实体扫描与非目标 Studio 读取。
- 无覆盖绘制需求时跳过 D3D9 设备状态检查；缓存窗口身份并按需检测焦点。
- 所有功能关闭且无其他需求时，降低相机与模块采集频率至 1Hz；激活后恢复正常频率，地图生命周期回调保持即时。

## 安装与兼容
完全退出游戏，备份并替换 L4D2Visual.dll，原有 hud.json 可保留。首次安装将 bin 合并到游戏目录。不要替换游戏自带 studiorender.dll。
FreeCamera ABI v4 保持兼容，建议搭配 DangoMusic v1.0.3。默认功能仍关闭。

## 验证与限制
本次整合包由 CI 回归、Windows x86 编译和安装包校验生成。候选包需实机确认后方可正式发布。性能改善取决于场景、MOD、驱动及菜单状态；不承诺固定 FPS。特殊模型、第三人称过渡及阴影绘制仍需实机验证。联机与 VAC 安全不作保证。
