# L4D2Visual v1.0.0 — 正式更新说明

**正式版本：v1.0.0**。支持 Windows x86 / L4N v2；安装包、匹配源码和 SHA-256 校验文件由 GitHub Actions 构建并上传。

本版本在 v0.8.0 的基础上整合第一人称身体、FreeCamera 和 Tank 建筑遮挡，优化关闭态渲染路径，减少对游戏原生状态的修改：

- **第一人称身体（FPB）**：世界原位身体、头部/手臂骨骼处理、动态定位、第三人称可选兼容及逐模型校准；移除纯观察型 ShouldDraw Hook，关闭后绕过模型读取。原生一字节 DrawModel 门控补丁具备 Clean/Patched/Unknown 三态、字节读回和恢复验证；异常时停止再次启用，不覆盖第三方修改。
- **FreeCamera**：WASD/鼠标自由飞行、Space/Shift 升降、最高速度调节、可选隐藏第一人称武器；菜单开关独立可用，F6 绑定默认关闭。三个 ClientMode Hook 改为首次请求启用才安装，关闭后原样透传。
- **Tank HUD 建筑遮挡**：采用只读的世界 TraceRay 检测。进度条、方向箭头及攻击范围提示同步遵守遮挡，原有目标连线不变。保留范围内红线、红色计时条和填充，**不再修改任何原生 Glow 属性**，也不包含特感描边。
- **性能与稳定性**：FPB 关闭时不进入 Studio 模型读取，共享 Render 与 D3D9 HUD 路径增加无效果快速透传，保留严格的游戏版本验证和默认关闭行为。
- **FreeCamera 联机鼠标处理改进**：Gap 保留转向输入，整型队列不截断累计量，附接收/应用/丢弃统计与低输入率回归测试。服务器实机效果仍待确认。
- **FreeCamera ExtraMouseSample 补全**：不再忽略 `command_number == 0` 的额外鼠标采样，允许渲染帧额外转向增量进入队列并保持世界人物方向锁定。此改动已经通过自动化测试，但服务器实机表现尚未确认。
- **其他原有功能**：实体缩放和周期拉伸、分类/准星识别、Tank 行为与动作计时、Tank 石头轨迹及静态世界落点继续保留。用户设置和历史配置尽可能兼容；旧 warnOutline 和喷漆配置被忽略。

默认情况下各新增视觉功能均关闭，F6 不被占用。主菜单将 Tank 石头预测排列在 FreeCamera 之前。支持 Windows x86 / L4N v2，仅对已验证的游戏 DLL 版本执行底层 Hook 或补丁。

**已知限制：** 服务器环境下此前有 FreeCamera 转向卡顿/部分转向未生效的反馈；本次增加额外鼠标采样处理，但未取得该修复在原服务器中的复验结论，不能视为问题已被确认解决。CI 测试不等于所有服务器、第三方 MOD、DXVK 或驱动环境的兼容性证明。不保证联机/VAC 安全。
