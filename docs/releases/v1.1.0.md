# L4D2Visual v1.1.0

本版本正式提供 FreeCamera 外部控制接口，并适配 2026 年 11 月更新后的游戏模块。

- **FreeCamera ABI v4**：支持 DangoMusic v1.0.0 的 AFK 自动运镜。外部接口默认关闭，需在菜单中主动授权；键鼠优先，可由调用方选择用户接管后恢复第一人称。
- **FreeCamera**：支持自定义快捷键及移动键；首次请求才安装相机 Hook，保留原生视角、闲置等待和所有权交接。
- **游戏更新兼容**：重新验证 client.dll、engine.dll、studiorender.dll 的接口、地址及相关机器码；未知构建仍拒绝对应 Hook 或补丁。适配 FPB、实体识别与变换、Tank 建筑遮挡和相机。
- **稳定性**：收紧停止、回调和资源生命周期，避免静态析构期间阻塞等待；保留原有默认关闭行为。

安装：完全退出游戏，替换 DLL 并保留自己的 hud.json；首次安装将 bin 合并到游戏目录。不要替换游戏自带 studiorender.dll。安装包、对应源码和 SHA-256 校验文件由 CI 生成。

联机及最新游戏环境中的所有功能尚未全面实测，不保证 VAC 安全。
