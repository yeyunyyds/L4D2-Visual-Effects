# 0.8.0 实体缩放与拉伸

默认关闭，支持已验证的 Windows x86 / L4N 客户端。联机功能未经测试，不保障 VAC 安全。

## 使用

根菜单 → 实体缩放与拉伸 → 选择分类 → 选择实体类别/角色 → 开启本项，选择整体大小或世界X/Y/Z轴比例，用 - / = 微调。整体大小和每轴倍率相乘，最终每轴10%–500%。普通菜单 - / = 翻页；精调页步长可在1%、5%、10%之间切换。倍率100%没有变化。最后开启实体形变总开关；完成后保存设置。

支持8种特感、8名求生者、场景可拾取武器/道具、第一人称及手持模型、其他内建模型类别和动态发现的Class ID。可通过「准星识别与调整」选择本体、候选或本机手持模型；识别使用经校验的游戏射线与身体范围，详见[识别说明](AIM-IDENTIFICATION.md)。作用于该类别/角色的全部匹配实体，不是单个临时实体编号。

各项独立设置优先于分类默认值，再继承全体默认值。独立关闭可排除某类；删除独立设置会恢复继承。根菜单可一键关闭全部类别。配置写入hud.json的entityTransform；总开关及各类别默认关闭，所有倍率默认100%，P2P等默认值不变。不要覆盖旧hud.json而不先备份。

第一人称手与武器作为整个视模一起缩放，枢轴是参与骨骼的位置平均值；世界实体以当前构建root或实际绘制origin为枢轴。各轴伸缩按世界坐标，不是模型朝向坐标。等比整体大小不受朝向影响。和邦友的酒同时开时，先应用本功能，再应用旧的脚部保持周期Z拉伸。

## 路径

自动模式首先采用Skeeto路径：有m_flModelScale的骨骼实体接入BuildTransformations，在上游构建结束后按骨骼mask处理并回写；玩家类感染者的等比缩放走客户端字段+RecvProxy。非等比玩家形变改用构建路径。扩展支持求生者、武器、ViewModel及可识别的其他模型。保留128/256运行时上限，入口也在本功能菜单。

对没有适用构建数据、构建校验不通过或尚未触发构建的目标，使用现有Studio DrawModel[25]绘制副本路径。已由构建缓存处理过的目标不再叠乘；同一实体后续用不同骨骼mask重建时保留已处理骨骼的覆盖。可以手动切换“Studio兼容”做对照；运行状态按类别列出等待/构建/字段/Studio/拒绝计数。

骨骼构建175槽及CStudioHdr/骨骼缓存字段依据相同x86客户端版本的Skeeto实现，受完整client.dll磁盘指纹、实体完整句柄和模型索引、MDL标识与骨骼标记向量校验约束。没有直接试调用未知槽位。整合测试版已通过用户验收；不保证所有第三方模型/插件组合的适用性。

关闭时在有效实体上按归属还原；地图失效则丢弃旧代次引用，不对新地图实体套用旧数据：骨骼只还原仍与本功能最后结果一致的部分；字段保存原值及后续原生网络值，不统一硬设为1；接收代理和构建Hook按所有权卸载，不覆盖其他模块随后接管的槽位。首次安装原生Hook后固定本DLL到进程结束，以免外部Hook链继续引用已卸载代码；更新DLL需完全退出游戏。

不写服务器状态或碰撞盒字段。原生路径会改变客户端骨骼缓存和附件姿态，不能当作纯像素变化。未开启或没有启用的非100%规则时，不安装本功能的构建/RecvProxy Hook。

## 覆盖边界与验证

所有已识别类别均可配置，但真正形变需要骨骼/Studio模型。BSP地图刷子、光束、粒子等没有这种绘制输入，不能靠当前Hook缩放；它们不会被计为成功。静态世界道具不属于网络实体目录时也无法按当前Class ID管理。

优先单个类别测试：普感（重点衣服）、Tank/Witch、求生者、垃圾桶/侏儒、场景武器、手与枪。逐项核对0.5/1/2倍、单轴伸缩、切图、实体重用、开关还原和128/256。先用自动模式，再切Studio对照。每个目标测试时只使用一套原生缩放控制；与其他第三方缩放插件叠加的结果未经验证。

邦友的酒和Tank原本共用同一个Studio接入层，均已包含原版studiorender.dll与此前版本的精确配置。原版上传DLL SHA256为3f5f5b0f539e8ad22bcfc4381be41571257c0c29e8061057682f9b8525ca7b85。本轮再次静态校验通过；邦友的酒“接口与日志诊断”可查看所选Studio配置。本次不捆绑游戏DLL/模型。

## 验证

28组原生回归与Windows x86构建通过，整合版通过用户验收。覆盖128/256矩阵、骨骼mask、锚点、缓冲事务、角色与类别规则、配置迁移、默认开关和菜单导航；保留两种已验证Studio配置。

内建道具识别与分类菜单共用类型规则；动态实体保留Class ID加类名校验。旧内建Class ID覆盖在加载时合并，保存后写回，不会自动打开形变总开关。
