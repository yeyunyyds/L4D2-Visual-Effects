# 0.5.1-test：优化与覆盖状态

本版没有 Windows 游戏内 FPS 对比数据。回归与交叉编译用于验证边界与构建，不代表所有实体或渲染组合已通过实机验收。

## 目标识别

- 按不可变实体快照和类别选择配置建立 entindex → record 及 entity base → entindex 索引。
- 非选中类别在读取当前实体字段前退出；Studio 直接路径使用基址索引，不再逐候选扫描。
- 类属性表在同一快照中按 class descriptor 地址缓存，避免每个 draw 重新遍历 RecvTable。
- 地图代次、250ms 快照时效、完整句柄 serial、renderable getter、休眠、当前类别及模型索引检查保留。当前内存身份不由缓存替代。
- 类别开关使用 Class ID；同类别的所有实体共享规则。菜单类别目录从已观察到的实体及其模块内 ClientClass 链表扩展，单次与全图均限制最多 4096 个描述符，不调用新的游戏虚函数。仍不能将此目录视作完整静态地图物件列表。

## 绘制诊断

统计键使用数字地图 epoch / classId / modelIndex，避免切图后的模型编号复用混入同一统计项。每个线程首次遇到一组目标时在共享登记表分配统计项，之后复用线程本地指针并使用 relaxed 原子计数；后续 draw 不拼接统计键字符串，也不逐次锁共享表。

日志线程每两秒格式化统计。登记上限 4096 项，超出时继续绘制但跳过新类别统计。全局阶段原因是近似诊断，在并行绘制下可能来自另一调用；不用于渲染身份判断。

## 骨骼缓冲

- 128 与 256 分别实例化独立、禁止内联的目标绘制函数，避免 128 模式仍预留 256 容量。
- 每次调用使用独立栈缓冲，支持嵌套绘制；缓冲一直存活至原始 Studio 调用返回。
- 移除骨骼数组默认清零和变形中间副本。只读取、检查和写入实际 count 根骨骼，剩余容量不复制。
- 先验证输入与变形结果的有限性，再写输出，拒绝时输出保持原样；不使用未经验证的直接引擎内存读取来替换 ReadProcessMemory。
- 128 模式对 count > 128 的模型保持原始绘制，不截断。256 模式仍拒绝 count > 256。模式切换不改变正在执行的调用。
- 无完整双脚的模型使用渲染根骨骼作为锚点；有双脚时恢复双脚及后代的完整原始矩阵。

## 快速绘制路径

提供运行时模式选择：默认完整兼容继续使用已验证的 cl_modelfastpath=0 路径；实验快速模式释放插件对该变量的控制。无已选择的当前模型实体、拉伸关闭或退图时也释放该变量。

这是供实机对比的设置，不是新的批量绘制 hook。快速模式可能漏掉可见主模型。完整批量路径的参数布局、目标关联与矩阵队列生命周期仍需以对应游戏 DLL 验证；当前环境缺少此前上传的 client.dll、engine.dll 和 studiorender.dll，未新增未经验证的调用或代码补丁。

建议在同一场景分别测量：效果关闭、完整兼容、快速模式。同时比较各类目标的可见变形与日志统计，避免将漏绘导致的性能变化当作完整覆盖优化收益。

## 准星附近识别与实体覆盖

复用 LDBDangoMusic experiment/entity-follow-v094 的网络姿态和视角 / 距离排序（提交 ce15a74704b943db33356eaba5153152f712daa1）。原实现是附近候选选择，不是实体碰撞射线，也不检测墙体遮挡。本版先显示候选名称 / Class ID，再由用户切换该类别。

识别和绘制不再限定特感白名单，但仍依赖有效网络模型身份与 Studio 绘制。静态地图道具、BSP 几何、客户端独有实体、无骨骼模型以及未进入当前回调的批量绘制不保证覆盖。垃圾桶等物理道具可能与其他物品共享 CPhysicsProp Class ID，开关按整个类别生效。

## 0.5.1 分类与范围实验

手动选择顺序为单项 Class ID 覆盖、分类规则、旧版全局默认。批量设置某分类会清除该分类的单项覆盖，不影响其他分类；原有 0.5.0 保存数据继续兼容。

范围实验默认关闭。以当前相机位置到有效触发实体网络世界姿态的三维距离计算；不按准星方向或遮挡筛选。默认 Tank / 500 游戏单位，允许 100～5000，步进 10 或 100。

实验活动只改变运行时筛选，不改写手动规则。临时规则排除手持模型、活动武器 / 物品句柄及其父链附件；普通感染者和可关联子实体默认排除，可单独开启。手持与排除集合只在快照 / 配置 / 实验状态变化时重建，绘制时不逐次扫描实体表。

当前快照、手动规则、实验设置或触发状态任一变化均使绘制目标索引失效重建。相机 / 实体快照过期、地图代次变化、目标休眠、隐藏或角色死亡时不会维持范围触发。目标位置采样间隔约 200ms；距离参考是相机，第三人称 / 观战与实体脚下位置不同。

进入触发范围时重启动画周期；离开时恢复手动规则。一键全部关闭同时关闭总开关和实验，并清空分类 / Class ID 开关；范围参数和目标选择保留。

普通感染者独立衣物不随身体变形的问题尚未修复。默认排除与独立参与开关用于限制此已知现象，并不代表其渲染路径已完整支持。
