# L4D2Visual 0.7.3-tank-animation-preview5

Tank 攻击动画来源诊断预览，仅依赖 L4N。正式版仍为 0.7.2。

**联机功能未经测试，不保障 VAC 安全。**

## 本次用途

定位普通挥拳是否出现在叠加动画层，以及实际客户端是否提供动画事件类。新增所有 Tank 动画层的序列、名称（可解析时）、进度、前一进度、权重与顺序；补充动画事件类的只读元数据，以及模型本地序列数量。

尚未验证游戏内的普通拳起手信号，本次不是“冷却已经修好”的版本。共享模型序列仍可能无法解析。没有新增事件 Hook，也不调用接收代理或修改游戏模拟。

## 安装与测试

1. 退出游戏，将压缩包中的 `bin` 合并到游戏根目录，替换插件 DLL。
2. 建议在本地单人测试。菜单打开“Tank 行为预测”，再打开“诊断记录”。不需要按 F7，也不需要人工标记。
3. 让同一只 Tank 普通挥拳数次、挥空数次，再丢石头后继续出拳，约 20～30 秒。
4. 退出游戏后提供 `bin/neko/plugins/L4D2Visual/tank-prediction.jsonl`。若生成了 `tank-prediction.previous.jsonl`，请一起保留。以实际原有日志目录为准。

日志为 schema 5。`actors[].animationLayers` 是自动采样；`animationLayerReason` 会说明为什么无法读取。`animationEventSchemas` 只是类和字段的元数据，不是已收到的事件。

本次不改变喷漆渲染、T 键绑定或联机默认配置。P2P 默认关闭；新采样随 Tank 预测关闭而停止。诊断记录默认关闭。原有手动计时入口保留兼容，但不作为这次调查和验证的依据。

## 安装包结构

根目录只有 `bin/` 和本 README。许可证位于 `bin/neko/plugins/L4D2Visual/licenses/`。回退时退出游戏后换回正式版 0.7.2 的 DLL。
