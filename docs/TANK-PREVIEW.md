# L4D2Visual 0.7.3-tank-style-preview9

Tank 样式预设、布局预览与显示修复。仅依赖 L4N，正式版仍为 0.7.2。

**联机功能未经测试，不保障 VAC 安全。**

## 三套整体样式

- 青金简约：青色朝向箭头、细范围弧、金色计时条。
- 琥珀战术：琥珀色方向、分段范围线、高对比刻度条。
- 冰蓝刻度：冰蓝方向与范围刻度、薄荷绿计时条。

预设同时调整朝向、范围和条的配色与线条；切换预设保留自定义位置与横竖方向。

## 预览与调整

菜单路径：**Tank 行为预测 → 样式预设与位置预览**。

左侧为设置，右侧是居中的简化 Tank 示意，带朝向、范围和两秒循环条。即使没有进入地图、没有 Tank 或没有开启预测，也可以预览。该循环为演示，范围为样式示意，不代表实时预测或真实攻击距离。

- 方向键移动条的相对位置；步长可切换 2 / 4 / 8 / 16。
- 菜单切换横条 / 竖条，调整长度和厚度。
- “重置位置与方向”恢复默认条布局，保留当前配色预设。
- “保存设置”写入现有 hud.json 的 tankVisual，下次启动恢复。
- 翻页仍为 - / =，0 返回；不改为左右键翻页。

条的位置现在相对投影后的 Tank 躯干中心计算，而非固定在头顶的世界高度。X 向右、Y 向下；大小和偏移按 1080p 参考尺寸等比缩放。预览和游戏内使用同一套条形布局计算，游戏视口边缘会对条进行钳制，避免条自身出屏。

## 黄条消失的处理

最新日志中计时仍有 210 条正值记录，周期为 2 秒；旧日志没有记录实际绘制状态，无法确定那次不可见的唯一原因。

修复代码中已确认的错误联动：Tank 绘制不再依赖喷漆 displayPaused。Esc 可暂时隐藏 Tank 覆盖层；游戏前台、插件菜单关闭后，检测到新的视角旋转便恢复。也可以在本页选择“恢复 Tank 显示”，或重新开启 Tank 绘制。喷漆继续保持原来的手动恢复规则。

恢复依据是视角变化，不是新增的游戏菜单可见性接口；不保证覆盖所有菜单、观战或镜头自动变化情况。没有新增未知实体虚函数调用。

schema 8 诊断加入 display：绘制开关、独立暂停状态、焦点、阻止原因、Present 绘制阶段、投影成功/失败计数、可见条数、绘制返回值、视口尺寸和投影矩阵。再次不可见时可开启诊断，提供 tank-prediction.jsonl 及 previous 文件，以区分暂停、出屏或 D3D 提交失败。

## 使用与计时限制

完全退出游戏后将 bin 合并到游戏根目录。实际绘制仍需开启 Tank 预测和方向与范围绘制；预览与自动计时均无需 F7 或人工标记，自动计时不需要开启诊断。

沿用 preview8 的实时前摇加普通攻击间隔估算；目前参数 0.5+1.5=2 秒。归零不代表已确认真实 AI 冷却或玩家安全，命中/挥空和投石恢复仍有限制。

事件字段样本校验、共享模型映射的已知限制保持。只有预测和诊断同时打开时沿用事件观察 Hook，关闭诊断则恢复；P2P 配置不变。

22 组原生测试（ASan/UBSan）、Windows x86 构建与安装包检查通过。新 DLL 和新预览页尚未在 L4D2 / DXVK 实机验证。样式设计图来自生产配色与条几何的离线绘制，不是游戏截图。

## 安装包结构

根目录仅 bin/ 和 README.md，许可证保留在 bin 内。正式版仍为 0.7.2；退出游戏后可换回正式版 DLL。
