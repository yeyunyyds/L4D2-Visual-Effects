# L4D2Visual 0.7.3-tank-layer-timer-preview7

Tank 攻击叠加层自动计时预览，仅依赖 L4N。正式版仍为 0.7.2。

**联机功能未经测试，不保障 VAC 安全。**

## 本次变化

将已经在日志中确认的攻击叠加动画接入自动计时：`Attack_Moving`、`Hulk_RunAttack1_gesture`、`Hulk_RunAttack2_gesture` 等可解析的攻击标签。按层的实际权重、序列及播放进度识别起手，而非硬编码 40/43/45 这些模型序列编号。

同一动作的持续采样不重复启动计时；连续同名动作可通过播放进度重启识别。处理多个攻击层混合、权重短暂归零后恢复、名称暂未解析、暂停、长采样间隔和实体句柄/地图变化。初次接入时若动作已播放到中途，不补造完整的新窗口。

读取实时普通/挥空间隔参数并采用较短值，从相邻采样的较早时间起估算；**这不是服务器真实冷却，也不保证倒计时归零后 Tank 必定能攻击或玩家安全**。投石单独处理，不套用普通拳间隔。

Tank 头顶计时条加粗至约 80 像素宽，黄色填充代表自动估算，菜单显示剩余秒数。仍使用现有 Present 绘制路径，没有增加场景阶段 GPU 调用。

## 安装与使用

1. 完全退出游戏，将压缩包中的 `bin` 合并到游戏根目录，替换插件 DLL。
2. 开启“Tank 行为预测”，并保持“方向与范围绘制”开启。
3. 让 Tank 出拳，观察头顶黄色条和菜单中的“观测估算剩余”。**无需 F7，无需人工标记。**
4. 自动计时无需开启“诊断记录”。如需反馈，可打开诊断并提供 `tank-prediction.jsonl` 及存在的 `tank-prediction.previous.jsonl`。

Tank 预测默认关闭，读取已保存的配置。自动计时取决于可解析的模型动画、有效层采样、推进的游戏时间与可读取的实时参数；信息缺失时保持未知。

## 验证与限制

21 组原生测试（ASan/UBSan）和 Windows x86 构建通过。离线回放用户提供的 782 条 preview6 样本，检测到 29 次起手、启动 29 次计时、209 条正值倒计时样本；对每条采样再重复输入，没有重复启动。

这是对已提供日志的回放结果，尚未在游戏中验证新 DLL。共享模型全局映射仍未实现，未知的序列不能直接认定为攻击。此次没有修复 preview6 的事件字段样本校验，动画层计时不依赖该事件通道。

“诊断记录”开启时仍沿用 preview6 的事件观察 Hook（必须同时开启 Tank 预测），原回调照常执行；关闭诊断则在下一游戏帧恢复。事件日志、绑定诊断、队列计数保留用于后续排查。未开诊断时，新计时不需要安装该事件 Hook。P2P 配置和喷漆功能不变。

schema 7 增加 `attackLayer` 的有效性、激活状态、起手、层号、序列、进度、权重和名称；`stopwatch.source=layer-observed-punch` 表示由攻击层启动。诊断写盘频率低于采样频率，单次 `onset` 可能未写入，但累计 `eventId` 和 `startedAt` 保留计时依据。

## 安装包结构

根目录只有 `bin/` 和本 README。许可证在 `bin/neko/plugins/L4D2Visual/licenses/`。退出游戏后可换回正式版 0.7.2 的 DLL。
