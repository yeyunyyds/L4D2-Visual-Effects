# L4D2Visual 0.7.3-tank-cycle-preview8

Tank 攻击叠加层自动计时预览，仅依赖 L4N。正式版仍为 0.7.2。

**联机功能未经测试，不保障 VAC 安全。**

## 本次修复

preview7 已识别攻击起手，但直接采用较短的挥空间隔作为完整周期，导致黄条过早归零。最新贴身连续出拳日志中，起手之间约 1.99～2.00 秒，旧黄条 span 却为 1.00 秒。

本版改为从动画起手估算普通完整攻击周期：**实时 tank_windup_time + tank_swing_interval**。这份日志读到 0.5 + 1.5，得到 2.0 秒；并非写死 2 秒。参数变更在下一次起手使用新值，缺少必要参数时不造固定计时。

没有确认命中/挥空时，不再把 tank_swing_miss_interval 擅自作为普通攻击的完整周期；挥空参数仍保留在诊断中。此公式与目前提供的贴身连续攻击吻合，但尚未证实所有攻击条件下的真实冷却。

**黄条仍是普通周期估算，归零不保证 Tank 必定可攻击或玩家安全。** 投石独立处理，不套用拳击周期。

黄条相对原先的头顶高度下移约 9%（世界空间锚点由 origin.z+100 调至 +91）。保留加粗的黄色填充、菜单剩余秒数和现有 Present 绘制路径。

## 安装与使用

1. 完全退出游戏，将压缩包中的 `bin` 合并到游戏根目录，替换插件 DLL。
2. 开启“Tank 行为预测”，并保持“方向与范围绘制”开启。
3. 观察连续出拳时的黄色条和菜单剩余秒数。**无需 F7 或人工标记，也无需开启诊断。**
4. 如需反馈，可打开诊断并提供 `tank-prediction.jsonl` 及存在的 `tank-prediction.previous.jsonl`。

Tank 预测和诊断默认关闭，读取已保存配置。自动识别继续基于已解析的 Attack_Moving / Hulk_RunAttack1_gesture / Hulk_RunAttack2_gesture 等攻击叠加动画，处理持续采样、动作重启、层混合、权重短暂失活、暂停、地图和句柄变化。

## 验证与限制

21 组原生测试（ASan/UBSan）和 Windows x86 构建通过。新增完整周期、缺失前摇参数、动态参数变更、挥空参数不再缩短普通周期等回归。回放最新贴身日志和先前日志，识别与重复采样去重继续通过。回放不是新 DLL 的游戏内验证。

事件字段样本校验和共享模型映射尚未修复；自动计时不依赖事件通道。“诊断记录”开启时仍沿用 preview6 事件观察 Hook（必须同时开启 Tank 预测），关闭诊断在下一游戏帧恢复。未开诊断时不安装该事件 Hook。P2P 和喷漆配置不变。

日志保留 schema 7，`stopwatch.span` 表示本次实际使用的估算周期，`startedAt` 和 `eventId` 可核对连续起手。实时 windup / interval / missInterval 分开记录。

## 安装包结构

根目录只有 `bin/` 和本 README。许可证在 `bin/neko/plugins/L4D2Visual/licenses/`。退出游戏后可换回正式版 0.7.2 的 DLL。
