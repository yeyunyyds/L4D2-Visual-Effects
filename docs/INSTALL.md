# L4D2Visual 安装说明

已发布的正式版本为 v0.8.0；当前开发分支的第一人称身体整合与设置调整
尚未单独发布新版本。完全退出游戏后再更新插件，并备份原有
`L4D2Visual.dll` 和 `hud.json`。

## 已发布版本：v0.8.0

该版本由 GitHub CI 构建与发布。对应源码标签为 v0.8.0：https://github.com/yeyunyyds/L4D2-Visual-Effects/tree/v0.8.0 。另提供 `L4D2Visual-0.8.0-source.zip`；源码提交号附在本 README 末尾。

## 安装

1. 完全退出游戏，备份当前 `L4D2Visual.dll` 与 `hud.json`。
2. 将本包 `bin/` 合并到游戏目录。需要已安装 Windows x86 L4N v2。
3. 保留自己的 `bin/neko/plugins/L4D2Visual/hud.json` 可继续使用原样式；第一次安装使用包内默认配置。旧图片和缓存文件可以自行保留，不再读取。
4. 从 L4N 插件菜单打开 L4D2Visual。版本信息以安装的 DLL 为准；本开发分支使用 `0.8.0-module-body` 标识，尚未发布新版本。

不要替换游戏的 `studiorender.dll`。首次使用原生形变/描边/场景射线后，更新插件必须完全退出游戏，不能只返回主菜单。

## 此包包含

- 邦友的酒与原版 Studio 兼容、128/256 骨骼模式。
- 实体整体/XYZ 形变，8种特感和8名求生者分类。
- 识别修复：场景射线、角色本体优先、候选切换、本机手持、统一类别设置、旧配置覆盖合并、切图清理。
- Tank 行为与动作计时、用户提供的 HUD 样式、范围内红色提醒。
- Tank 石头预测：独立主菜单入口、绿色轨迹、红色落点、外观设置。未实现刀石或 JSONL 采集。

## 默认与入口

所有功能总开关默认关闭，包括第一人称身体；第三人称视角兼容也是默认关闭的可选项。Tank 的条/朝向/范围等显示偏好保留；新配置红线提醒默认开启，红底、填充、描边关闭；入口为「Tank 行为预测 → 显示内容 → 攻击范围内提醒」。旧配置中的显式 false 不会强制改成 true。

石头入口为「Tank 石头预测[关]」：开启后轨迹及落点默认开，轨迹500 ms、绿色80%不透明度、2 px；落点圆红色50%、半径32游戏单位。预测采用固定重力320与假定半尺寸16的碰撞箱，仅估算静态世界接触，不保证真实落点，也不是伤害范围。落点查询不可用时不画假落点，轨迹仍可独立显示。

已验收的已有功能保持原设置；更新后可逐项检查识别、形变、Tank 提醒和石头，以及同时开启、Esc/恢复、切图和关闭还原。不同地图、MOD 或第三方插件的组合仍可能影响效果。


安装包根目录仅有 bin/ 和 README.md。许可证在 `bin/neko/plugins/L4D2Visual/licenses/`。GPL-3.0，第三方出处见随包 NOTICE.md 和另附完整源码。

自定义喷漆功能已移除：不再提供图片加载、T 键绑定、P2P 同步或自动发现。旧配置中的 `wallPictures` 与 `sprayP2P` 被忽略，下次保存设置时不再写出；已有图片与缓存文件不会自动删除。
