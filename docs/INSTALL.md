# L4D2 Visual Effects 0.7.4-compat-preview1

Windows x86 / L4N v2 客户端视觉效果插件。

**联机功能未经测试，不保障 VAC 安全。**

退出游戏后将 bin 合并到游戏根目录。安装包根目录只有 bin/ 和 README.md，完整源码在 GitHub compat/studio-tank 分支；许可证在 bin 内。

包内默认配置为 bin/neko/plugins/L4D2Visual/hud.json。所有功能默认关闭：邦友的酒/实体类别/范围实验、喷漆、T 绑定、自动换图、P2P、自动匹配、Tank 预测、绘制及各显示项、诊断、F10。兼容绘制选项和横竖方向属于样式/兼容参数，不是功能总开关。

**升级时包内 hud.json 会在手动合并覆盖时替换旧配置；先备份原文件。** 新安装或使用包内配置会全部关闭。若保留旧 hud.json，则沿用用户之前保存的开关，不会擅自重置。

默认 Tank 样式采用用户确认配置：冰蓝刻度、竖条、X=-32/Y=-24、整体55%、长度88/厚度8、箭头大小100%、箭头和范围线宽3倍。仅导入样式，未导入上传配置中开启的功能、图片选择、文件名或联机名单。

开启 Tank 总开关后，在“显示内容”打开画面及所需计时条/箭头/范围/目标连线。在“样式与位置预览”调整布局，进入各精调页选参数，- 减少、= 增加；普通菜单仍为 - / = 翻页。完成后保存设置。

位置随实体与透视缩放，优先使用新鲜渲染位置。计时为自动攻击动画起手后的普通周期估算，不代表真实 AI 攻击资格、命中或安全窗口。没有 SourceMod 依赖。

自定义喷漆通过图片目录选择使用；联机与自动匹配必须分别手动打开。P2P 默认关闭时不会创建其传输连接；不要将默认关闭理解为 VAC 安全保证。

Tank 诊断和事件观察默认关闭。需要反馈时在高级诊断手动开启，提供 tank-prediction.jsonl 及 previous 文件。事件字段校验仍有限制；共享模型采用经过结构校验的只读映射，实际游戏兼容性待验证，自动计时不依赖该事件通道。Esc 显示恢复依据仍为视角变化或手动恢复，并非已验证的游戏菜单可见性接口。

本次为兼容性预览：支持上传的原版 studiorender.dll（SHA256 3f5f5b0f539e8ad22bcfc4381be41571257c0c29e8061057682f9b8525ca7b85）及此前版本。接口工厂、对象、虚表、DrawModel 参数清栈及骨骼布局已静态核对；client.dll / engine.dll 仍限现有已验证版本。

Tank 身份按实体匹配，不再依赖模型文件名。动作优先依据 ACT_* 语义，缺少有效语义时才采用动作标签；不再把原日志中的 40/43/45 等序号当作通用约定。模型名称、地址、校验值或序列表变化会重置识别历史，避免更换 Mod 后沿用旧动作。

共享动画通过只读 CStudioHdr / virtualmodel 序列组映射解析，校验根模型、向量、组索引及局部描述符；不调用未知游戏函数。未能验证映射或完全自定义的活动名称仍显示未知，不猜测攻击。新原版 DLL 已静态验证；原版 Tank 及不同 VPK 的实际游戏表现仍需测试，不能据此前 Mod 日志宣称已实测兼容。

测试时开启 Tank 总开关、画面和计时条；连续近身出拳及投石后观察。需要诊断时再手动开启日志，记录约 30 秒；普通使用不需要开启诊断。全部功能默认关闭及用户选定的默认样式保持不变。
