# L4D2 Visual Effects 0.7.2

求生之路2视觉效果插件，适用于 L4N v2 / Windows x86。

**免责声明：联机功能未经测试，不保障 VAC 安全。**

## 安装

1. 完整退出游戏，确保已安装 L4N v2。
2. 将压缩包内 `bin` 合并到游戏根目录，确保只加载一份 `bin/neko/plugins/L4D2Visual.dll`。
3. 通过 L4N 菜单打开 L4D2Visual 0.7.2。
4. 更新不会覆盖个人图片、hud.json 或日志。卸载时退出游戏并删除插件DLL。

## 邦友的酒（拉伸）

进入“邦友的酒[关]”，在实体分类中选择目标，再开启总开关。
支持八名求生者、八种特感、物品等分类开关，以及动画、128/256骨骼容量和范围实验。
总开关及实体类别默认关闭。`- / =` 翻页，`0` 返回。

## 自定义喷漆

1. 图片放在 `bin/neko/plugins/L4D2Visual/images/`，支持 PNG、JPG/JPEG、BMP。
2. 进入“自定义喷漆”，开启模块、刷新目录、选择图片并等待加载。
3. 对准平整墙面，点击放置。
4. “按键、切图与数量限制”中可开启T键绑定和喷后自动下一张；两项默认关闭。使用T前关闭插件菜单。
5. 默认最多两张，超出后删除最早图片，数量可调1～8。
6. 大小默认长边60，可逐文件保存，立即调整已喷图片；支持“仅当前”和“应用所有”。放大后超出墙面支撑范围会保留原尺寸。
7. 点击“保存设置”保存参数；已喷图片不跨地图保存。

按Esc会暂停喷漆显示。返回游戏后，在喷漆菜单手动“恢复喷漆显示”，原图片不会清空。

## 联机实验

**联机功能未经测试，不保障 VAC 安全。** 联机总开关默认关闭。
双方均须安装本版并开启联机；同局自动匹配默认开启，最多探测三名其他真人。
普通L4N客户端不能接收本插件喷漆。多人服务器可切换手动名单模式，详见在线说明。
不要把发布为正式版理解为联机功能、反作弊兼容或所有渲染组合已经通过验证。

## 已知限制

- 使用用户确认基础正常、T键正常的0.7.2绘制路径；已撤回0.7.1导致DXVK闪烁/崩溃的场景GPU绘制改动。
- 当前未实现手部和武器的正确深度遮挡，喷漆仍可能覆盖它们。0.7.1请停用。
- 世界遮挡采用采样，部分被墙挡住时可能整张隐藏，并非原生decal。
- 大图最长边缩放到2048像素；CPU/GPU缓存各64MiB，仍有画面备份开销。
- 自定义聊天键或第三方输入界面无法完整识别，必要时关闭T绑定。

配置和日志：`bin/neko/plugins/L4D2Visual/`；日志约4MiB轮转，保留当前和previous两份。
