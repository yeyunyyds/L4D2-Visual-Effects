# L4D2Visual 0.8.0 正式版

本版基于通过用户验收的整合测试版，由 GitHub CI 构建与发布。正式源码标签为 v0.8.0：https://github.com/yeyunyyds/L4D2-Visual-Effects/tree/v0.8.0 。另提供 `L4D2Visual-0.8.0-source.zip`；源码提交号附在本 README 末尾。

## 安装

1. 完全退出游戏，备份当前 `L4D2Visual.dll` 与 `hud.json`。
2. 将本包 `bin/` 合并到游戏目录。需要已安装 Windows x86 L4N v2。
3. 保留自己的 `bin/neko/plugins/L4D2Visual/hud.json` 可继续使用原样式；第一次安装使用包内默认配置。图片目录不用清空。
4. 从 L4N 插件菜单打开 L4D2Visual。主菜单标题应显示 **0.8.0**，用来区分此前测试 DLL。

不要替换游戏的 `studiorender.dll`。首次使用原生形变/描边/场景射线后，更新插件必须完全退出游戏，不能只返回主菜单。

## 此包包含

- 邦友的酒与原版 Studio 兼容、128/256 骨骼模式。
- 实体整体/XYZ 形变，8种特感和8名求生者分类。
- 识别修复：场景射线、角色本体优先、候选切换、本机手持、统一类别设置、旧配置覆盖合并、切图清理。
- 本地喷漆及原有控制设置；P2P 与自动发现默认关闭。
- Tank 行为与动作计时、用户提供的 HUD 样式、范围内红色提醒。
- Tank 石头预测：独立主菜单入口、绿色轨迹、红色落点、外观设置。无刀石或 JSONL 采集实验。

## 默认与入口

所有功能总开关默认关闭。Tank 的条/朝向/范围等显示偏好保留；新配置红线提醒默认开启，红底、填充、描边关闭；入口为「Tank 行为预测 → 显示内容 → 攻击范围内提醒」。旧配置中的显式 false 不会强制改成 true。

石头入口为「Tank 石头预测[关]」：开启后轨迹及落点默认开，轨迹500 ms、绿色80%不透明度、2 px；落点圆红色50%、半径32游戏单位。预测采用固定重力320与假定半尺寸16的碰撞箱，仅估算静态世界接触，不保证真实落点，也不是伤害范围。落点查询不可用时不画假落点，轨迹仍可独立显示。

整合测试版已通过用户验收；更新后可逐项检查识别、形变、Tank 提醒和石头，以及同时开启、Esc/恢复、切图和关闭还原。不同地图、MOD 或第三方插件的组合仍可能影响效果。
