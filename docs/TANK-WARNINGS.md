# Tank 攻击范围内提醒与建筑遮挡（v1.0.0）

入口：**Tank 行为预测 → 显示内容 → 攻击范围内提醒**。Tank 总开关默认关闭；红色范围线选项默认开，红色进度条背景与填充默认关。三项提示都只是原有 D3D9 HUD 绘制，不修改原版 Tank 的实体属性。

| 提醒选项 | 玩家进入预估攻击范围时的变化 |
| --- | --- |
| 进度条红色与红底 | 已启用的计时条改为红色，并加深红色底，即使计时数据缺失也可提示 |
| 攻击范围红线 | 当前攻击扇区的线条、边界与刻度变红 |
| 攻击范围红色填充 | 当前攻击扇区使用半透明红色填充 |

提醒根据存活的本机求生者完整句柄及 Tank 当前攻击扇区计算，不用相机位置或 Tank 索敌对象代替玩家身份。高度与水平距离根据网络实体和碰撞信息作近似；判断当前扇区，不额外扩大实际命中范围，也不要求攻击冷却完成。切图、死亡、句柄重用和过期数据不会继续沿用旧状态。

## 建筑遮挡

入口：**Tank 行为预测 → 显示内容 → 计时条/箭头/范围：建筑遮挡**。

`tankPrediction.occludeHud` 默认 `true`，但只有 Tank 行为预测总开关和画面显示开启时才工作。使用现有的 `EngineTraceClient003::TraceRay` **只读调用**，不增加 Hook，不写入 Glow。每个 Tank 最多对身体三个高度采样点进行世界几何射线检测，通常每约 50 ms 更新，结果短时间缓存。

当 Tank 的身体采样点被建筑阻挡时，该 Tank 的 **计时条、方向箭头、攻击范围线、前瞻线和范围红色填充** 一起隐藏；目标连线维持原有逻辑。任何一点确认为可见时显示相关 HUD。射线不可用或结果过期时按遮挡处理，不绘制虚假的透视标记。

这不是深度缓冲或逐像素测试。对于动态物件、透明物件、半遮挡、非世界几何体，判断与真实画面可能不一致。范围仍是客户端预测，不代表实际攻击命中或安全距离。

## 删除原生 Glow 修改

**v1.0.0 不包含 Tank 红色原生描边，也没有独立的特感描边。** 旧版 `tankPrediction.warnOutline` 配置被忽略，并在下次保存时移除。不存在 `SetGlowType`、颜色 RecvProxy 或原生 Glow 类型/颜色/范围的写入与恢复路径。

建议在不同墙体、楼层、多个 Tank、暂停/恢复、地图切换及有其他 MOD 的情况下测试遮挡一致性。**不保证联机/VAC 安全**。
