# Tank HUD 本体遮挡与独立特感描边（实验分支）

基线：`experimental/free-camera-73c6dc8a` @ `4036c2f03cc61987f04e0d4a9b1d857d3765a651`。本分支保留 FreeCamera/第一人称身体的现有改动，不修改 LDB/DXVK。

## Tank HUD 本体遮挡

路径：**Tank 行为预测 → 显示内容 → 计时条/箭头/范围：建筑遮挡**。Tank 总开关仍默认关闭；打开 Tank 预测后，本体遮挡默认开启。可单独关掉以恢复旧的 HUD 透视行为。

进度条、朝向箭头、攻击范围圆弧与径向边界、红色扇区填充、刻度线及前瞻虚线全部共用同一 Tank 本体可见性结果。Tank 本体被墙体遮挡时，这些提示一并隐藏；只开启攻击范围（关闭进度条）时仍进行遮挡检测。目标连线保持原逻辑，不参与遮挡。

在 Source 游戏线程，每约 50 ms 调用已有经过验证的 `EngineTraceClient003/TraceRay`，向 Tank 头、胸、下半身中的最多三个点发射 world-only 射线。任意一点无遮挡即允许显示；均被遮挡则隐藏；射线/相机/实体数据无效或检测失败时默认隐藏。采用世界几何的整体开关，不是 D3D Z-buffer 逐像素裁剪。可被世界 BSP 墙体遮挡，不保证动态门、道具、静态模型或透明材质的行为。可见性会在最多约 350ms 后过期，避免旧数据产生持续透视。

## 独立特感描边

入口：**特感描边 → Smoker/Boomer/Hunter/Spitter/Jockey/Charger/Tank/Witch**。特感描边首页增加 **一键开启/关闭全部描边** 与 **一键开启/关闭全部墙壁遮蔽**：任一项未全开时点击就全部开启；全部开启时点击则全部关闭。批量操作不修改单独颜色，单类开关仍可覆盖批量设置。八类分别提供：
- 描边开关，默认全部关闭；
- 独立 RGB 颜色，进入 **某特感 → 颜色预设 · 选择** 子菜单，从 10 种具名颜色直接选取（当前预设标记为「已选择」）；也可返回特感页对 R/G/B 每次加减 16。选色立即生效，保存后以 `[R,G,B]` 的形式存入 `hud.json` 的 `specialGlow.<类名>.color`；
- 建筑遮挡开关，**默认开启（不透视）**：关闭遮挡时采用原生 Glow Type 3（Constant）；开启遮挡时先进行世界几何 LOS 检测，然后采用原生 Type 2（LOS/OnLookAt，非恒定模式）。该模式在个别模型可能不稳定，也不保证始终出现轮廓。已经保存为 `occlude: false` 的旧配置会继续尊重用户选择，只有未配置时默认开启。

这不是重绘模型的 Shader，也不依赖 D3D9 的深度纹理。实体必须已经出现在本机的有效网络实体目录中，且尚未死亡、休眠或丢失。本机并不拥有未被服务器发送的所有地图实体，因此“常驻”不代表全图扫描。

**原生 Glow 状态：** 延续原有严格的 client.dll 哈希、指令和 RecvTable 校验，只接管原 Glow Type=0 的实体，不强行覆盖游戏或其他 MOD 的已有描边。当前 Tank 攻击范围内红色提醒拥有更高优先级；提醒解除后若 Tank 的独立描边仍开启，就恢复对应的类型/颜色。关闭任一功能时恢复仍归本功能所有的原属性。未能验证身份时直接跳过，不使用未知的写入地址。

## 性能与失败模式

- 所有 TraceRay 与 Glow 修改都发生在 Source 线程；D3D Present 只读取原子发布的只读可见性快照。
- 每轮最多处理 12 个实体的 LOS，每个实体最多 3 条射线；每 50ms 最多进行一轮；同一实体一般至少隔 90ms 再探测。
- 每轮候选最多 64 个，按顺序轮询；角色切图、死亡、离开实体目录、关闭设置时丢弃缓存和原生属性租约。
- 射线绑定拒绝、失效、实体快照过期时，所有要求非透视的提示按不可见处理；穿墙描边本身不需要 TraceRay。
- Glow 的原生 Type 2/3 兼容性仍需实机验证；已有 Glow 的实体会保留原有结果，未必按配置改变颜色。
- 与主线一致：联机和 VAC 安全未经验证，存在兼容性风险；如原生 Glow 已接管实体，更新 DLL 建议完整重启游戏。

## 推荐实机验证顺序

1. 只开启 Tank 预测：墙前/墙后/半遮挡/楼梯/多 Tank，确认进度条、箭头、范围线、填充与预测虚线同步隐藏；关闭进度条仅保留攻击范围时依然受遮挡控制，目标连线不变。
2. 验证特感一键全开/关、一键遮挡全开/关后独立颜色保持原值；逐个进入颜色预设子页选择十种颜色之一，检查 RGB 微调与保存/重载，再测试 Smoker、Hunter、Charger 和 Witch 的 LOS/Constant 两种模式。
3. 同时开启 Tank 蓝色常驻描边与原有红色攻击警告，确认优先级正确；来回进出攻击范围，恢复预设颜色。
4. 测试同局多特感、玩家死亡、切图、断线、菜单关闭和重进、已有其他描边 MOD。
5. 分别使用原生 D3D9、LDB/DXVK、FreeCamera 和第一人称身体组合测试稳定性。

本次修改只提交源码、配置与回归测试用例，**未编译 DLL、未执行测试，也未进行游戏内验证**。之前的成功构建不包含本次新增功能。开发分支的 CI 已改为手动触发。
