# FPB 均值校准实验 1
基于 v1.1.0 main，不合并此前无效的 native byte probe。诊断版仅在 FPB 启用且本机存活身份通过校验时，在普通视角持续放行已验证的原生 JZ；第三人称兼容开启时，非第一人称保留完整骨骼。FreeCamera 逻辑保持原样。不保证额外原生渲染路径，也不保证 VAC 安全，建议单机。
 
## 采集
FPB_DISTANCE 每50ms至多一次，在 Studio 的 FPB 修改之前记录 chest/eye 距离、水平和高度分量，以及模型局部 XYZ 修正、flags、姿态、原点几何、模型及 checksum。这里的骨骼是 FPB 修改之前的输入，可能已经被共享管线其他特效修改。眼位为绑定姿态估算，不是真实眼球位置。每20条或1秒批量输出，不在每次 draw 写文件；末尾不足一批可能未写出。第三人称也采集，只要原生 Studio 路径实际进入。FreeCamera 不采集。
 
## 动态定位2
动态定位子页独立开关，默认关闭；开启后优先于原定位。通过已发现 m_fFlags 的 FL_ONGROUND/FL_DUCKING 分类为站立/走动、下蹲、腾空（含下落和蹲跳）。未找到字段则 unknown，不训练，不猜偏移。以严格的第一人称候选（shoulder=0、原点XY<=12、现有几何First；兼容开时还需已提交First）作为训练门槛。不是绝对视角真值。以模型肩部基底计算原始眼位估算的修正，不含手动偏移。每状态30个至少相隔50ms的样本（站/蹲稳定至少150ms），取算术平均并冻结，不再追随相机。未学完只应用模型局部手动偏移；不回退到持续吸附。姿态切换直接选择各自固定均值，暂不插值。朝向跟随只属于旧算法，新算法仅保留手动 yaw。换图、玩家handle、模型、回退高度、开关或手动重新采样均重置；内存中存储，未持久化。兼容开启时非First不修改骨骼；新模式即使兼容关仍要求严格第一人称候选，否则保留原生骨骼。该限制用于实验训练/应用，不是最终视角分类方案。
 
## 测试
保留原 hud.json，仅替换 DLL。开启 FPB、第三人称兼容，先保持动态定位2关闭：站立、走跑、蹲走、反复跳跃、连续打包及手动第三人称。然后开启动态定位2，原地和走动约数秒，蹲走约数秒，多次跳跃，打包和第三人称对照。观察 FPB_MEAN frozen 日志与是否出现身体漂移。提供 L4D2Visual.log 与大概动作时点。若 flags=-1，需后续确认字段解析；不会生成假均值。自动编译不代表实机验证。
