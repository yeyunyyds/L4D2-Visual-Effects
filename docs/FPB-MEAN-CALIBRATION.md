# FPB mean.3 测试版
基于 mean.2。只在验证存活本机实体后保持普通视角原生门控放行；FreeCamera 与关闭/身份失败时的恢复机制不变。
## 距离兼容
开启第三人称兼容（或动态定位2）后，在 Studio 骨骼修改前按原始模型估算眼位与同次绘制相机的距离决定是否修改。明确 shoulder=1 或距离 >=28 立即原生通过；距离 <=24 持续80ms恢复；中间区域滞回。无眼位估算则回退原视角证据。距离不是视角真值，阈值来自 mean.1/2 数据，尚未实机验证。仍可能因其他原生绘制路径消失。FreeCamera不采集。
## 定位2
定位1实际成功 transform 后，采集其 filtered translation 和 yawRadians，转到原始模型肩部局部坐标。含原算法的手动及模型偏移，不再次叠加；采用同一 pivot 与 transform。仅严格第一人称候选且眼位距离<=24、模型局部基底有效才训练。三姿态分别30样本、至少50ms间隔，站蹲稳定150ms。开启定位1时即可采集，开启定位2后若该姿态未冻结仍由定位1实际渲染，已冻结则直接复用固定均值。关闭定位2不丢失学习数据；切图、handle、模型、有效偏移/yaw/回退高度/朝向跟随改变或重新采样会使均值失效。只存内存。姿态切换无插值，仍需测试。
## 日志
FPB_DISTANCE 保留原距离字段，增加 path=native/teacher1/mean2、actualLocal 与 actualYaw，缺失为 nan。FPB_MEAN frozen source=teacher1 记录完成的均值。采样20Hz；未进入 Studio 路径无法记录。最后不足批次可能丢失。原始骨骼指 FPB 修改前输入，其他共享特效可能已处理。
## 验证
先开 FPB、第三人称兼容、定位1，定位2关；测试打包和第三人称，以及走、蹲、跳。再开定位2观察已学姿态是否复现，未学姿态继续使用1。用重新采样清除三组。单样本复现、距离滞回及均值冻结加入回归测试，不代表实机成功。
