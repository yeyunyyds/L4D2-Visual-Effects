# FPB view.1 实验说明（非正式版）
mean.3 的后续测试。动态定位2、均值数据及菜单全部移除；旧 hud.json 的 dynamicAnchor2 被忽略并在保存时移除。动态定位1算法与 main 一致。保留原生门控持续放行方案和 FreeCamera 原生骨骼旁路；身份验证失败、关闭、退出仍恢复原生字节。

开启第三人称兼容时，使用同次 Studio 绘制相机、实时安全读取实体原点及原始骨骼。立即退出骨骼处理：明确 shoulder=1、估算眼位距离>=28、相对实体原点高度>66，或80ms窗口中原点总位移<=0.75且相机水平相对距离>=4并增长>=1.5。高度<=64.5、水平脱离锁存回到<=2.5、眼位距离<=24且持续80ms才恢复；无眼位估算回退到已有第一人称证据。静止特征不是必要条件。关闭兼容时保持用户原有不限制定位的行为，并记录 compat-off。阈值是单机日志启发的实验值，不是普适常数。

返回时独立检测原始头部骨骼距离：相机接近头部（<=10，退出12）且处于恢复确认或正在接近时，可以仅隐藏头部（用户开关开启），不移动身体、不隐藏双臂。FreeCamera 已明确旁路，不执行上述处理。过早隐藏及网络插值误判需要实机验证。

FPB_DISTANCE 新增 origin/camera 世界坐标、originMotion、relativeGrowth、stationary、detached、head、reason、compat、actualWorld。FPB_VIEW 在路径/原因变化时立即记录，便于定位过渡瞬间。距离仍20Hz批量记录，末尾未刷新的样本可能丢失。没有进入 Studio 的帧无法观察。原始骨骼指 FPB 修改前输入。

测试：开启FPB/第三人称兼容/动态定位/头部隐藏，正常跑跳蹲、打包开始结束、肩部第三人称切换、倒地与控制、FreeCamera。对照日志判断是否提前停止与是否有误判。纯策略回归覆盖静止、跳跃、下蹲、横向脱离、高度变化、头部提前隐藏、明确第三人称及原距离兜底；不等同实机验证。
