# 0.4.0-test：动画预设、0.1微调与局部性能优化

默认500ms、0.5～1.1；三条有界周期曲线：平滑、Q弹衰减回弹、双跳。
整数毫秒/十分之一比例保存，周期±100ms、比例±1，避免浮点累加漂移。

校验和、地图代次改变时重建，头部失效时拒绝，模型缓存容量限制64。

保持已实机确认的兼容渲染路径，未声称完成批量渲染接入或获得某个FPS提升。
