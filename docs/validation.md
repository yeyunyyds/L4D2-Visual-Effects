# 0.4.0-test：动画预设、0.1微调与局部性能优化

# 0.5.2-test：修正固定目录与空间范围语义

上一版误以相机接近目标作为全局触发，且菜单仍依赖已观察类别；本版移除这两项行为。

新增回归要求：空场景下八种特感完整列出，武器 / 手持模型等预定义类型直接可设；
类型在出现前设置并保存，出现后正确生效；既有数字 Class ID 配置可继续使用。
范围用例同时包含近 / 远两个同类型实例，验证仅近者生效；相机从目标旁移到远处，
结果不变；手动开关为开也不能越过实验范围；多个中心取并集，中心消失后移除其范围。
保留死亡、隐藏、休眠、地图、时效、手持物 / 附件与普通感染者排除测试。

八组 ASan/UBSan 回归和 Windows x86 编译用于验证本地实现，不替代游戏内验收。
